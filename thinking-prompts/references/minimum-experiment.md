# 决策：用最小实验替代空想

## 适用场景

- 用户已经纸上谈兵很久，需要低成本现实反馈。
- 用户想验证某个选择、想法或方向是否值得继续。
- 用户说“最小实验”“低成本试一下”“怎么验证”。

## 输出强度

- 轻量：找出一个关键假设，设计一个明天能开始的小实验。
- 标准：列出 3 个假设，选出最关键假设，并完整设计实验。
- 深度：增加指标、继续/停止阈值、风险控制、资源投入和实验复盘方式。

## 追问与初版判断

如果缺少周期、资源或选择背景，先问一个关键问题；如果可以先设计初版实验，直接输出并列出本次使用的假设。

## 模板复用输出

用户要求可复制 Prompt 时，输出最小实验的定制模板，不直接替用户做实验设计。

## 模式切换

如果用户还没明确要验证的选择，切换到双向钢人论证；如果用户要核查某个假设事实是否成立，切换到事实核查。

## 执行规则

找出决定背后最需要验证的 3 个假设，再选择最可能改变最终结论的那个假设，设计一个低成本、可逆、限定周期内能完成的最小实验。

## 原 Prompt 模板

```text
我正在纠结的是：【填写你的选择或想法】。请先找出这个决定背后最需要验证的3个假设，再选出最可能改变最终结论的那一个。围绕这个假设，帮我设计一个低成本、可逆、能在【7天或你能接受的周期】内完成的最小实验。请写清：1. 具体要做什么；2. 需要投入多少时间和资源；3. 观察什么指标；4. 什么结果支持继续；5. 什么结果提醒我停止；6. 实验结束后能获得什么新信息。最后告诉我，明天就能开始的第一个动作是什么。
```
