# 学习：横纵分析法

## 适用场景

- 用户要深度研究产品、公司、人物、技术、行业或事件。
- 用户需要历史脉络、关键时间线、横向对比和未来路径判断。
- 用户要求来源、证据、报告结构或较长篇幅研究。

## 证据纪律

- 涉及当前事实、公司状态、法规、价格、排名、市场格局、人物职位等可能变化的信息，必须联网核查。
- 联网能力不可用时，不得假装完成当前事实研究；明确说明限制，转为提供研究框架、待核查问题和建议来源。
- 优先使用官方资料、原始数据、论文、财报、访谈等一手来源。
- 重要结论就近标注来源与日期。
- 事实、推断和观点分开写。
- 冲突信息并列呈现，找不到证据时明确写“暂未核实”。

## 输出强度

- 轻量：给出核心结论、极简时间线、关键对比和 1 到 3 个待确认问题。
- 标准：按输出顺序完整覆盖结论、时间线、横向对比、分析和未来判断。
- 深度：更接近原 Prompt 的长报告形态，扩展一手来源、冲突证据、路径依赖和预警信号。

## 追问与初版判断

研究对象、时间范围或研究目的不清楚且会影响结论时，先问一个关键问题；如果可以先做初版研究框架，直接输出并列出默认假设。

## 模板复用输出

用户要求可复制 Prompt 时，输出横纵分析法的定制 Prompt 模板，不直接开始研究。

## 模式切换

如果用户从系统研究转为核查某个具体说法，切换到事实核查；如果只是想听懂一个概念，切换到双层解释法。

## 输出顺序

1. 核心结论。
2. 关键时间线。
3. 横向对比表。
4. 详细分析。
5. 未来判断。
6. 仍待确认的问题。

## 原 Prompt 模板

```text
研究对象是：【填写产品、公司、人物、技术、行业或事件】。请使用横纵分析法，对它完成一份可追溯的深度研究。研究截止时间为执行当天。纵向分析：1. 它在什么背景和需求下诞生，关键推动者是谁；2. 它经历了哪些重要转折、成功和失败；3. 哪些早期选择变成了今天的能力、路径依赖或包袱。横向分析：1. 选择最值得比较的对象，并说明为什么选它们；2. 用统一维度比较各自的强项、短板和独特性；3. 解释用户、客户或市场为什么选择它，又为什么放弃它。把两条轴合起来，继续判断：1. 过去形成的能力、路径依赖和约束会怎样影响未来；2. 未来最可能出现哪3条路径；3. 每条路径出现的前提和预警信号是什么。请遵守这些证据规则：1. 优先使用官方资料、原始数据、论文、财报和访谈等一手来源；2. 重要结论就近标注来源与日期；3. 事实、推断和观点分开写；4. 遇到冲突信息时并列呈现，找不到证据时明确写“暂未核实”。最后按以下顺序输出：核心结论、关键时间线、横向对比表、详细分析、未来判断、仍待确认的问题。报告需要在10000～30000字之间，语言尽量通俗，不要堆砌资料。
```
