# 解决问题：第一性原理

## 适用场景

- 用户想回到本质、推倒重来、摆脱路径依赖。
- 用户的方案像是在不断打补丁，需要从基本事实、目标和约束重新推导。

## 输出强度

- 轻量：列出基本事实、未验证假设、新路径和验证第一步。
- 标准：完整区分事实、假设、目标、资源约束，并重新推导可行路径。
- 深度：加入更多假设拆解、路径依赖分析、反常识选择和验证设计。

## 追问与初版判断

如果目标或约束不清会影响推导，先问一个关键问题；如果可以先推导初版，直接输出并列出本次默认假设。

## 模板复用输出

用户要求可复制 Prompt 时，输出第一性原理的定制模板，不直接执行推导。

## 模式切换

如果用户需要多个专家互相质疑，切换到专家会诊；如果用户想找其他领域相似解法，切换到跨领域借解。

## 执行规则

拆回最底层：

1. 已确认且无法绕开的基本事实。
2. 习惯性接受但未验证的假设。
3. 真正想实现的目标。
4. 现实资源与约束。

暂时放下行业惯例和现成方案，只从事实、目标和约束重新推导路径。

## 原 Prompt 模板

```text
我想解决的问题是：【填写你的问题】。请用第一性原理把它拆回最底层，区分：1. 已经确认、无法绕开的基本事实；2. 习惯性接受、却没有验证过的假设；3. 真正想实现的目标；4. 现实中的资源与约束。暂时放下行业惯例和现成方案，只从基本事实、目标和约束出发，重新推导可行路径。最后请输出：1. 原方案中只在修补表面的部分；2. 从基本事实重新推导出的新路径；3. 这条路径成立的前提；4. 验证它的第一步。
```
